# One-time cloud recovery, not a new experiment

Human approval: safe migration to free standard cloud CPU and one finite recovery
allowance amendment. Original plan, model commit, seeds, reward, learning rates,
15,000,000 interactions/cell and original seven-day deadline stay fixed.

The cumulative segment ceiling is now96/cell, INCLUDING all historical local
segments (48/1/1/1 for the four convergence cells). Nothing is restarted at zero.
No extra training seeds, parameters, paid runners, artifact/cache storage or
unknown-outcome retries are allowed. Code/numerical failures stop expansion.

This directory is orchestration only. Each runner checks out model commit
4a17b77d98970fe090531420479020c607f4dfb9 separately as `frozen/`; the original
model and experiment code are not edited or replaced. Runtime provenance is
recorded separately, including the Windows-to-Linux execution transition.

The original run remains read-only. Its `recovery_20261019/` subdirectory holds
an explicitly linked continuation ledger, immutable policy, parent ZIP receipts
and the original plan. Parent source/config, CSV, environment/RNG/optimizer and
checkpoint prefixes are inspected before cloud resume. Raw data are never
merged with a fresh initialization. Final results include original prefixes.

The original finite coordinator is reused through explicit execution adapters:
cloud ownership only,96 cumulative segments, unique recovery tags, immutable
Release checkpoint chains and remotely executed raw-data gates. The local
parent is standard-library only and keeps one temporary idle-sleep request;
training is on up to16 standard public ubuntu22.04 runners, evaluation one at
a time. The four convergence cells start as four independent cloud jobs.

After the original convergence gate: original auxiliary/scaling/C1/sensitivity
order,24 training cells/360M interactions total. C1 is copied and reused, not
recomputed. Failed learning gates and unknown cloud outcomes stop the queue.
The gate is not a demand that TMAPO wins. Final heldout data do not tune models.

No changes to main. No publication of the paper/PDF or private historical data.
